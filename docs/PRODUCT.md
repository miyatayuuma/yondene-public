# 製品仕様

## 本棚と読書記録

本棚には登録済みの本と書影・書誌・出典付きあらすじを表示する。既定の絞り込みは「読んでる・読んだ」。検索、状態、並び順を切り替えられる。シリーズ画面は登録されたシリーズを巻順で表示し、巻番号と番外編を区別する。別版の参考書影を表示する場合は明示する。

読書状態は `unread`（きになる）、`reading`、`paused`、`read`。読む方法、期間、記録の出典を保持し、旧データの読了日・期間も表示する。読了日の精度は利用者の申告に合わせる。本人の感想と保護者要約を区別し、★は子ども本人が選んだ1〜5。承認済みのアプリ機能とChatOpsを通じて書き込む。アプリ内の状態訂正には更新前条件と対応する記録が必要。

## 家族と推薦

GoogleログインとFirestore Rulesで家族のアクセスを管理する。管理者はメンバー、家庭内の本棚と読書記録、期間付きの一回限りの招待を管理する。旧メール招待の発行済み分も扱う。閲覧メンバーは自分のプロフィール、許可された交流機能を使う。管理者がメンバーを外しても新しい招待で再登録できる。

推薦は一人分の記録を保ったまま同一作品をまとめ、共同推薦では推薦者ごとの説明を表示する。推薦の登録と本棚への追加は別操作。最近の活動は最新の公開可能な投稿や読書記録を家族内に表示し、感想のプレビューを優先する。

## 正本と画面の責務

| 責務 | 実装 |
| --- | --- |
| 認証、家族セッション、購読と画面切替 | `app.mjs` |
| 本棚・シリーズ一覧 | `bookshelf-view.mjs`、`domain.mjs` |
| 書誌詳細、読書記録、感想、★の画面統合 | `book-details.mjs` と各機能モジュール |
| おすすめ・最近の活動 | `recommendations.mjs`、`activity.mjs` |
| プロフィール、メンバー、招待 | `family-settings.mjs` |
| 森の素材・権限・起動 | `book-forest-access.mjs` |

既存Firestoreのコレクション、文書ID、Rules、更新履歴の形式を引き継ぐ。家族セッションの購読や編集画面を閉じる際は同じ単位で解放する。PWAはAndroid Chromeを主対象に、アプリアイコンだけをService Workerで扱う。HostingはHTML・JS・CSSを再取得させ、実行中のビルド識別子を設定画面で確認できる。
