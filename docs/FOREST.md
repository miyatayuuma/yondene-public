# 本の森

## 探索とキャラクター

管理者の設定から起動する。季節と月は日本時間で切り替わる。Three.jsの地形・接地・影、橋と水辺、歩行スプライト、移動・カメラの操作を使う。スプライトは非公開Driveから管理者のGoogle認証で取得する。音声は発話テキストをタップしたときに再生する。ふたごは発話ごとに再生できる。ふたごの2人とイシシ・ノシシの各組はそれぞれ同じ音声設定を共有する。ねこの身振りと筆記を読み上げない。

`forest-character-registry.mjs` がNPC ID、配置、関係、出力モード、音声を共有する。通常の追加はレジストリへの登録、非公開スプライト、非公開人物設定で行う。人物像、口調、行動例、根拠は人物台帳で更新する。管理者の「人物設定・会話を更新」で再読込する。キャッシュの有効期限は1時間。

## 一本の会話経路

1. `book-forest-topics.mjs` が現在の本棚と資料から話題を決める。伝言と初対面を先に扱い、その後は人物に関係する承認済み既読記憶、感想、森の雑談を選ぶ。新たに読了した本を優先し、直近3回の会話に出た記憶は通常の候補から外す。日付で雑談と候補順に変化を付け、当日に会ったNPCと関係を文脈に渡す。
2. 感想は直近14日分を優先し、古いものは関係する既読本を最大2冊調べる。引用と保護者要約を区別する。同じ日に同じ本の感想を繰り返さず、感想を扱う会話の間には他の訪問を挟む。
3. `book-forest-live-dialogue.mjs` が、人物設定、根拠付きの場面、直前の応答を生成入力にする。HTTPリクエストはFirebase管理者IDトークン付きで正式Workerへ送る。WorkerがJSONと安全性を検証し、ブラウザが表示と選択に必要な契約を確認する。
4. 冒頭と選択後の応答を生成する。最後の選択肢は直後の答えと同時に生成する。訪問と話題の履歴は生成された場面を表示したときに確定する。資料が撤回された場合は以後の送信・応答を止める。失敗時は短い終了または非発話の身振りで探索へ戻る。

日次上限はUTC基準。訪問あたり最大3リクエスト。会話を閉じると生成を中止する。ログには限定した診断情報を記録し、感想を使った生成本文や選択肢は端末ログに残さない。開発確認に保存済みの全文を使う場合は非公開環境内で扱う。

## 出力

通常NPCは日本語の発話と選択肢。ふたごは同じ生成経路から話者スロットを2件受け取り、1件ずつ表示する。初対面では現在のペアの名前を名乗る。既に覚えたペアIDは端末内で引き継ぐ。

ねこは `delivery: gesture` の括弧付き動作か `delivery: written` の意味のある筆記を返す。筆記はひらがな、小学1年の配当漢字80字、必要な句読点・空白を使い、読みやすさ用の空白を除いて65字まで。話者の内面の声や、人語の発話は禁止。台帳の人物設定を他のNPCと同じ形式で取得する。

人物の原作内経験、森での即興、他の本の感想を聞いた第三者としての反応を区別する。既読の承認済み事実を使い、未確認の原作事実や子どもの私的情報を推測しない。未知植物の摂取の促し、不正な話者・文字、追加操作を前提とする終話候補などを共通検証で除外する。
