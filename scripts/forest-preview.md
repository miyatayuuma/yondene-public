# 本の森のローカル目視確認

リポジトリのルートで `python3 -m http.server 8000` を実行し、`http://localhost:8000/scripts/forest-preview.html?month=4&view=start` をブラウザで開く。`month` は 1〜12、`view` は `start`, `bridge`, `forest`, `valley`, `hill` を指定できる。

キャラクター画像は検証用に生成した仮画像で、実際の非公開 Drive 画像ではない。表示品質や接地、実際の認証・画像取得の受入確認は、別途、管理者として本番相当環境で行う。ブラウザの Android 縦画面と実機の両方で、歩行、視点、会話、終了、再入場を確認する。
