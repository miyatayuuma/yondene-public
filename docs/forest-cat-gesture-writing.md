# 本の森｜非発話NPCの共通人物設定と文字出力

## 設計原則

ねこも**他のNPCと同じ人物設定・関係性・場面選定・生成エンジン**を使用する。
人物像の正本は、非公開の「よんでね｜本の森 キャラクター設定・セリフ台帳」の
`人物設定` と `根拠資料` を参照する。
公開レジストリには ID、`mode:'silent'`、`outputMode:'action-writing'`、
画像・位置・関係するIDだけを保持する。**人格・価値観・口調・エピソードを公開コードに書かない。**

人物設定が読み込めないときは、固有の性格を捏造してGemmaに生成させず、
承認済みの非発話フォールバックへ戻す。設定更新は次回の非公開素材の再読み込み後に反映する。
人物設定がない理由は登録診断で確認可能。

## ねこの原作資料とその確度

ニック・シャラット『ねこと王さま』（市田泉訳、徳間書店）について、
ねこが王さまの生活を実務的に支える相棒であることは次の公開情報による。

- 児童文学専門家の書評： https://jbby.org/book/10912
- 公共図書館の紹介： https://libweb.city.setagaya.tokyo.jp/kidscontents?1=&pid=360
- 続編で仕事のリストを作る紹介： https://www.oml.city.osaka.lg.jp/licsxp-opac/WOpacTifTilDetailToKanRenDetailAction.do?kanrenflg=1&returnflg=&tilcodtmp=1000015084144
- ねこが人語を話さないという読後レビュー： https://readinglist-cbya.hatenablog.com/entry/the-cat-and-the-king
- 付箋の文字についての読書評： https://www.kinokuniya.co.jp/f/dsg-01-9784198650032

非発話・付箋に関する記述は二次情報で、日本語版の本文を直接照合したものではない。
地面や葉っぱへの文字書きは**ゲーム独自の演出**であり、原作内の出来事と断定しない。
調査で得た人物像は公開GitHubに複製せず、非公開Sheetsの資料根拠付き人物設定から参照する。

## 共通の生成経路と非発話の出力モード

1. 現在のFirestoreの既読状態、会話履歴、人物関係から共通ディレクターが話題・場面を選ぶ。
2. 非公開Sheetsの人物像・話し方をほかのNPCと同じパーサ・検証ルールで読み込み、Gemmaへ送る。
3. `outputMode:'action-writing'` のNPCも会話本文は `text` に返す。`delivery:'written'` の本文は、ひらがな・カタカナ・小学1年生の配当漢字80字・句読点・空白で65字以内とする。
4. 身振りで意味が伝わるときは `delivery:'gesture'` と括弧付きの行動描写を返せる。Workerとブラウザで同じ出力検証を行う。
5. 会話欄では書いた本文の上に固定の補足を表示する。履歴と次の生成には本文と伝達種別を記録する。ねこの行動と書字はどちらも読み上げない。

本番配信と検証の手順は [本番経路の統合会話検証](forest-integrated-conversation.md) を参照。
