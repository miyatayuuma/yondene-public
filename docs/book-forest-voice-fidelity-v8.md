# 本の森 — 口調エンジン v8

## 最優先の受入条件

登場人物としての性格・関係性・状況への反応・話し方を、共通テーマの深さ、会話量、AI生成頻度より優先する。
人物ごとに無理に教訓や問いを作らない。短い驚きや観察、会話の間も有効とする。
原作の事実、児童の安全、家族情報の保護は緩和しない。

## 生成フロー

1. 認証済みの非公開台帳から承認済み台本と人物設定を読む。設定欠落時はAIを使わない。
2. `base.start()` が選んだ承認済み第一声を保持する。共有の「思考の種」で台本選択を強制しない。
3. 同じ人物の `meet` / `ambient` 承認済みセリフから最大2例を取得する。`story` / `reflection` および書籍・記憶ID付きの文は例示しない。
4. 第一声・人物設定・例示・子どもの選択をモデルへ渡し、短い返答を1回生成する。原作にない出来事、キャラ設定の説明、毎回の教訓は禁止する。
5. 入力された台詞の形式・明白な一人称違反・自分の名前による三人称回想などを検査。語尾や口癖を毎回要求しない。
6. 応答候補3個は先頭2個に正規化し、良いNPC台詞まで破棄しない。短い一言や終了時の空の選択肢も受容する。
7. 生成失敗時は元の台本の継続を試し、不可ならキャラ別の別れの文に戻る。3回目以降の訪問はAIのみ停止する。

「思考の種」は承認済みの `story` 台詞と同一記憶IDで一致したときだけ、出典確認済みの事実とテーマを渡す。
哲学的な軸・対立する見方・他NPCとの会話履歴をモデルに一律注入しない。

## 検証

- 自動：誤った一人称、人物名による自己回想、三候補、短い一言、終了時の空候補、日内3回目、AI失敗時の台本復帰、書籍の既読解除、ふたごと猫の例外。
- 実生成：王さま・キキ・ジジ・スキッパー・ゾロリ・イシシ・ノシシの7名で、雑談・意外な出来事・選択への返答を各2回（計42発言）。
- 人物取り違え、重大な原作捏造は0件。個性の手動評価は5段階で4以上を目安にし、キャラごとの典型的な失敗が残れば見直す。

テストのモック出力は実際のGemmaの人物再現度の証拠にはならない。
Worker・Hosting・実機での受入は別々に報告する。
