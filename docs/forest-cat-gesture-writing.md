# 本の森｜非発話NPCの共通人物設定と文字出力（v17）

## 設計原則

ねこも**他のNPCと同じ人物設定・関係性・場面選定・生成エンジン**を使用する。
人物像の正本は、非公開の「よんでね｜本の森 キャラクター設定・セリフ台帳」の
`キャラ設定` および `話し方`。原作の事実は同じ台帳の `原作資料` に保持する。
公開レジストリには ID、`mode:'silent'`、`outputMode:'action-writing'`、
画像・位置・関係するIDだけを保持する。**人格・価値観・口調・エピソードを公開コードに書かない。**

人物設定が読み込めないときは、固有の性格を捏造してGemmaに生成させず、
承認済みの非発話フォールバックへ戻す。設定更新は次回の非公開素材の再読み込み後に反映する。
人物設定がない理由は登録診断で確認可能。

非発話・付箋に関する記述は二次情報で、日本語版の本文を直接照合したものではない。
地面や葉っぱへの文字書きは**ゲーム独自の演出**であり、原作内の出来事と断定しない。
調査で得た人物像は公開GitHubに複製せず、非公開Sheetsの資料根拠付き人物設定から参照する。

## 共通の生成経路と非発話の出力モード

1. 現在のFirestoreの既読状態、会話履歴、人物関係から共通ディレクターが話題・場面を選ぶ。
2. 非公開Sheetsの人物像・話し方をほかのNPCと同じパーサ・検証ルールで読み込み、Gemmaへ送る。
3. `outputMode:'action-writing'` のNPCだけ、発話ではなく `text`（括弧付きの状況・動作）と
   任意の `mark`（表示面と書いた文字）を要求する。
4. 書くことが不自然なら `mark:null`。**毎回文字を書く必要はない**。
   `mark` がある場合も、`text` の自然な行動説明は必須。
5. `mark.surface`: `note`（紙）、`ground`（地面）、`leaf`（葉）。
   `mark.word`: ひらがな・長音符・小学1年生の配当漢字80字・「、。！？」のみ。
   1〜48文字はAndroidの3D表示に合わせた暫定的な**表示上限**であり、人物の知性の上限ではない。
   意味のある一〜二文を認め、適切な場面では短い一語も認める。
6. Workerとブラウザの両方で出力文字・非発話条件を検査する。
   モデルが文字座標・HTML・描画命令を指定できないようにする。
7. ねこの音声読み上げは引き続き無効。API失敗時も口頭の別れのセリフを表示しない。
   会話終了時は3D文字のCanvasTexture・Geometryなどを解放する。

**実際の意味内容が原作の人物像に沿っているか**は自動テストだけで保証できない。
Gemma実生成の受入は本番WorkerとHostingの反映後に別途確認する。

## テストと配信

- 非公開Sheetsから読み取った設定だけを変更すると、生成プロンプトが変化すること。
- 設定欠落時に推測人格で生成しないこと。
- 初対面・再訪問・読了記憶・感想反応に共通の状況選定が使われること。
- 文字を書かない場合も自然な `text` が表示され、TTSが起動しないこと。
- 配当外漢字・カタカナ・英数字などを拒否し、配当内漢字の複数行メモを描画できること。
- 既存NPC・ふたご・Firestore Rules・PWA/Workerビルドの回帰検証。
