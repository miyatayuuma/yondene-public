# 本の森「声の実験室」とセリフ読み上げ

同じセリフを使って声を選ぶ独立した検証ページ。2026-11-11に本の森の会話画面にも再生操作を統合。

## 開き方

- ローカル: `reading-shelf-firebase/forest-voice-lab.html` を端末のブラウザで開く。HTML単体で動作し、Firebase認証や通信は不要。
- 開発中のローカルサーバーまたは後日Hostingに配信した場合: `/forest-voice-lab.html`。
- ソースを変更したら `node scripts/build-forest-voice-lab.mjs` でHTMLを再生成する。

## 比較と共有

1. キャラを選び、A/Bで共通の短いセリフを入力する。
2. 「Aを聴く」で現在の基準を再生。「B」の音声・速さ・高さ・音量を変更し「Bを聴く」で比較する。再生中に別の声を押すと前の読み上げを停止する。
3. 良いと判断したBを「基準に採用」。キャラ別にブラウザのlocalStorageへ保存する。
4. 全キャラ分を試したら「採用設定を表示」のJSONを開発担当に共有する。

ブラウザ/端末によって日本語音声の種類、読み上げ品質、pitchやrateの効き方が異なる。個別キャラの声質を細かく保証するものではない。試聴は実際に使用するAndroid Chromeで行う。自動クラウド音声生成、音声ファイル保存、録音・子どもの発話送信は行わない。

2026-11-11の試聴フィードバックにより、初期値を全員早口に変更し、速度の調整上限を2.00へ拡張。イシシとノシシは`ishishi`、ふたご2人は`twins_first`の設定を共有する。以前の別枠保存値は代表者の設定を優先して移行する。`cat`（ねこ）や未知のキャラIDでは、エンジンが音声再生を拒否する。

## 本の森に実装した再生仕様

- 会話のセリフは自動読み上げしない。吹き出し全体ではなく**文字ブロックの領域**を押した場合のみ、そのセリフを読み上げる。
- ふたごは会話全文を読み上げず、**選んだセリフ1件のみ**2人共通の声で読む。再生中は会話の自動送りを一時停止し、終了後に次の待機時間を再開する。
- 読み上げは再タップや場面遷移で停止可能にする。選択肢のタップ判定とは干渉させない。
- ねこは文字を押しても再生しない。音声合成非対応の端末では再生対象の操作自体を作らない。
- 日本語発音の補正辞書を使うが、表示テキストは変更しない。
- 同じWebオリジンで試聴ページが保存したプロファイルを読み込む。別オリジン（ダウンロードした`file://`ページ等）の保存値は自動では移らないため、その場合はコードの初期プロファイルを使う。

## 配信について

GitHubでのコード公開とFirebase Hostingへの配信は別。HTML/JS/CSSを新しくデプロイして初めて、本番アプリの文字ブロックが読み上げ可能になる。実際のAndroid音声再生は端末で受入確認する。
