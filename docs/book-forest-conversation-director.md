# 本の森 — 会話ディレクター v0.1

## ねらい

森で NPC に話しかけるたび、同じあいさつを繰り返すのではなく、読書の進み具合、以前の会話、本人の感想、相手の性格によって話題が変わる。子どもの操作は短い選択肢だけ。**ランタイム LLM は使用しない**ため、会話ごとの推論料金・トークン消費はない。

## 情報源と秘匿

- 本棚と `childReflections` の現在値は Firestore が正本。認証済み owner のブラウザが既存の Firestore 権限で読み取り、書き込みはしない。
- 作品の出来事は非公開「物語記憶」タブ（出典があり `approved` の短い事実のみ）。書名から読了を推測せず、Firestore の `book.id` と `status:'read'` で許可する。
- 台詞は非公開「会話台本」タブ。本文は原作の引用ではなく独自の短文。`approval:'approved'` のみ使用し、キャラ別の台詞、無言の猫の所作、感想への反応、他キャラへの引き継ぎを記録する。
- 公開 GitHub に実際の bookId、台詞本文、非公開 Sheet ID、個人の感想、Google アクセストークンを置かない。コードと架空 ID のテストのみ公開する。
- Sheets の内容は Google Drive で認可された所有者のブラウザだけが HTTPS の Sheets API で読み取る。既存画像と同様、会話台本と物語記憶は所有者・家族で分離した端末キャッシュに保存し、ログアウトと「森の素材を更新」で消去できる。**本文の全件が所有者の端末へ渡る設計**であり、信頼できない端末での利用は避ける。感想本文はキャッシュしない。
- 会話の進行状態は端末の `localStorage` に訪問回数、承認済み台本・記憶・感想の不透明な識別子、既読本IDの集合、直前の引継ぎ先を保存する。新たな読了を検出するための既読本IDも含まれるが、感想原文、会話本文、発話ログは保存しない。家族やユーザーが変われば別のキーになり、明示的なログアウト時に削除する。

## 話題選択の仕様

1. 本棚の最新スナップショットで `read` の本だけを許可。未承認・未出典・結末ネタバレの記憶は排除。
2. 初対面はあいさつを優先。初めての相手に、前の NPC からの引き継ぎがあっても、最初はあいさつから始める。選択肢で「本の話」へ続けられる。
3. すでに会った相手なら、NPC からの引き継ぎを優先し、**元のエピソード ID** を渡す。後から未読状態に戻った本の事実は除外する。
4. まだ使っていない正式な本人感想・保護者要約を優先する。本人原文と保護者要約は語り分ける。取り消された感想は既存コレクションに存在しないため表示しない。
5. 前回訪問以降に `read` へ変わった本の事実を優先。次に未使用の物語記憶を選び、同じ話を連続して出さない。
6. 本・感想がなければ、キャラごとの日常台詞を出す。データ取得に失敗しても探索自体は継続できる。

9 種類の会話 ID に、初対面9、日常18、物語9、感想9、会話の引継ぎ9の **54件**の独自台詞を非公開台帳に追加した。物語9件はひな型で、公開出典に基づく物語記憶（現時点34冊／121件）から毎回異なるものを選べる。表示される NPC は10体だが、ふたご2体は同じ会話人格を共有する。

## 非公開「会話台本」の列

`schemaVersion | cueId | npcId | kind | bookId | memoryId | fromNpc | text | choicesJson | approval`

`kind`: `meet`, `ambient`, `story`, `reflection`, `relay`。

`story` は `{memory}`、`reflection` は `{reflection}` のテンプレートを使える。`reflection` の `bookId` は対象本を特定する（全本の子ども感想を一括取得しない）。`relay` は直前の NPC を `fromNpc` に指定し、前回の話に紐づく物語記憶を `{memory}` に挿入できる。

`choicesJson` の例（架空・実データなし）：

```json
[{"id":"another","label":"ほかの話を聞く"},{"id":"visit","label":"別の子にも聞く","text":"向こうにも行ってみよう。","relayTo":"cat"}]
```

## 動作・費用

- Forest 起動時に台帳発見のため Drive API 1回、読み込みのため Sheets API 1回。2回目以降は端末キャッシュを使う。
- 登場人物に話しかけた時、必要な感想は対象本ごとに最大5件だけ Firestore から読む。メモリと会話台本選択は端末内処理であり、トークン消費0。
- 会話が好みに合わない、記憶が偏る場合は、別の台本を追加・承認する。表情や行動は原作の具体的な記述と区別して独自演出として監修する。
- 当面は「設定 → 本の森 → 森の素材を更新」で非公開台本を再取得する。Sheets API が対象 Firebase プロジェクトで未有効の場合、ユーザーによる Google Cloud Console の有効化が必要。Google アカウント承認も初回だけ必要になる可能性がある。
