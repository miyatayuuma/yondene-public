# 本の森 AI Worker

`yondene-forest-ai` は、Firebaseの管理者IDトークンと許可済みオリジンを確認し、Workers AIのGemmaを使って会話を生成する。公開 `GET /health` は版・プロトコル・レジストリ・構成状態、`POST /dialogue` は認証済みの生成。生成回数・入力サイズを制限し、JSONと児童向け出力の契約を検証する。

プロンプトには人物設定、既読事実、会話の状況、必要な場合は短い感想や保護者の要約を含む。モデルへの送信ではFirestoreの家族・書籍IDやGoogle認証情報を含めない。認証に必要なトークンはWorkerの認証処理で使う。非公開環境の設定・資格情報を公開コードに追加しない。

正規の配信コマンドと受入は [運用・配信](../../docs/OPERATIONS.md) を参照。
