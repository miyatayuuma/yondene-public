# 本の森 — キャラらしさ優先 v7

## 判断基準

会話は「全員が有益なことを言う」ための装置ではない。ひと言の驚き、いたずら、間、観察、反応だけでもよい。**その登場人物にしか自然に言えないこと**を、情報量・正しい教訓・共通テーマの網羅性より優先する。

- 今日の「思考の種」は全員が言及すべき課題ではなく、使うか選べる背景。話が広がらなければ日常的な一言でもよい。
- スキッパーに大声で冒険を案内させない。ジジを相談員にしない。キキを万能の励まし役にしない。イシシとノシシの反応を同一化しない。王さまを威厳一辺倒にしない。
- 語尾や口癖を毎行に強制しない。人物の大切にしていること、行動、相手との関係、相手への返し方を含めて「らしさ」を見る。
- 子どもの興味・感情を決めつけず、実際には話していない原作の台詞を作らない。

## 実装

1. 所有者だけが閲覧できる「よんでね｜本の森 キャラクター設定・セリフ台帳」の `キャラ設定`、`話し方` を、既存の認証済み読み取りリクエストに追加する。
2. 列名と NPC ID で結合し、検証済み人物像・一人称・話し方・関係性・回避事項を有限長で抽出する。引用・セリフ標本・私的な読書記録・所有者情報は送らない。口調の根拠が暫定的な場合は断定を避ける。
3. 端末の所有者＋家族ごとの非公開会話キャッシュを v5 へ更新。従来の台本・物語記憶・思考の種・双子の動作を維持する。
4. 生成時に対象 NPC の設定だけを渡す。設定欠落時は生成しないで承認済み台本を表示する。
5. 明白な他人称・異性の一人称等は軽量な検査で拒否。微妙な口調の良否は機械的な語尾検査で判断せず実機検証で受け入れる。

## 受入観点

1. 同一のテーマをスキッパー、イシシ、ノシシ、ジジ、キキで試し、文の主語・関心・反応・テンポが区別できること。
2. テーマを無視した短い自然な雑談も失敗としない。いずれの NPC も毎回質問や教訓で閉じないこと。
3. 素材を更新した後、キャラ設定が見つからない端末ではAIの汎用発話をせず、既存の承認済みセリフが出ること。
4. 猫は人語を話さず、双子は承認済みの掛け合いを維持し、音声読み上げの操作を壊さないこと。
5. 添付会話ログで観測された「ジジの女性的な案内口調」「イシシ・ノシシの普通の案内役化」が再現しないかを観察すること。

実機でのセリフ品質はモデルの生成結果に左右されるため、テストコードが通っただけで受入完了とはしない。
